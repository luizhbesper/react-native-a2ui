## M1-T3..T7 — Basic catalog in 5 sessions

Order: **T3 layout** (Row, Column, Card, Divider, List incl. template lists via FlatList) → **T4 content** (Text with markdown-lite, Image, Icon) → **T5 inputs A** (Button + action dispatch, TextField two-way, CheckBox two-way) → **T6 inputs B** (Slider, ChoicePicker, DateTimeInput — JS-fallback implementations, Expo Go safe) → **T7 containers + media stubs** (Tabs, Modal, Video/AudioPlayer placeholder cards).

Per session, uniformly:
- **Test-first (Jest/RNTL), per component:** renders from schema-shaped props; bound props react to data writes; inputs write back on user interaction (`fireEvent`); action components dispatch with correct source/context. Edge cases: missing optional props, null bound value, empty template list.
- Props/types generated or transcribed from vendored schemas with a comment pointing at the schema path.
- **Exit per session:** components exported from the package root; RNTL green; STATUS.md updated.
