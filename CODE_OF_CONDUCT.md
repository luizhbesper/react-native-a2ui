# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**TL;DR:** be respectful, be constructive, no harassment of any kind. Disagreements are about code and ideas, never about people.

Report unacceptable behavior to luiz.hb.esper@gmail.com. Reports are handled confidentially. Maintainers may remove, edit, or reject contributions and contributors that violate this code.
